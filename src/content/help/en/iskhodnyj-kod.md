# Source code

Ugolok is an open-source project. Anyone can study exactly how everything works inside, and confirm that the claimed encryption and privacy model are implemented the way they're described, not just claimed in words.

Project repository: **git.ugolok.tech**

Over time, it will also host:

- ready-made builds (releases) of the app;
- a list of known issues and requests — you can report a problem you've found or suggest an improvement;
- more detailed technical notes for those who want to dig into implementation details or help the project grow.

The project is young and keeps changing actively — if something in this help section diverges from the app's actual behavior, trust what you see, and if you can, report it through the repository.
