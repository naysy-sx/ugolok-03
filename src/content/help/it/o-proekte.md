# Informazioni sul progetto

**Ugolok** è un servizio di messaggistica senza un'unica azienda e senza un unico server al comando. Funziona invece sopra il protocollo aperto **Nostr**: chiunque può gestire il proprio server (un relay), e persone su server diversi possono comunque scriversi tra loro.

## Perché è importante

- **Nessuno può semplicemente spegnerlo.** Se un server viene bloccato o smette di funzionare, le persone possono passare a un altro senza perdere nulla: un account si basa su una coppia di chiavi crittografiche, non su una password nel database di qualcun altro.
- **Le conversazioni sono cifrate** in modo tale che nemmeno il proprietario del server attraverso cui passano i messaggi possa leggerne il contenuto.
- **Puoi avviare un tuo server personale** se non vuoi dipendere nemmeno dai server del progetto — Ugolok è pensato apposta per questo.

## A chi è rivolto

- A chi vuole parlare con le persone care senza il rischio che qualcuno di esterno si interessi alla conversazione.
- A chi ha bisogno che la comunicazione continui a funzionare anche in presenza di restrizioni e blocchi attivi.
- A chi, per principio, non vuole dipendere da una singola azienda e dalle sue regole.

## Cosa sa già fare Ugolok

- Messaggi privati con cifratura end-to-end e protezione contro la lettura retroattiva (vedi la pagina «Privacy»).
- Canali — qualcosa a metà tra un post sui social e una chat di gruppo, con controllo flessibile su chi può leggere e commentare.
- File e allegati — con un proprio archivio cifrato.
- Chiamate vocali.
- La possibilità di avviare un proprio server e avere il pieno controllo dei propri dati.

Ugolok è un progetto vivo, che continua a cambiare e crescere. Questa guida cresce insieme a lui.
