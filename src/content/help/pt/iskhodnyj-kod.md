# Código-fonte

O Ugolok é um projeto de código aberto. Qualquer pessoa pode estudar exatamente como tudo funciona por dentro e confirmar que a criptografia e o modelo de privacidade anunciados estão implementados da forma como são descritos, e não apenas afirmados em palavras.

Repositório do projeto: **git.ugolok.tech**

Com o tempo, também aparecerão lá:

- builds prontos (releases) do aplicativo;
- uma lista de problemas e pedidos conhecidos (issues) — você poderá relatar um problema encontrado ou sugerir uma melhoria;
- notas técnicas mais detalhadas para quem quiser se aprofundar nos detalhes de implementação ou ajudar no desenvolvimento do projeto.

O projeto é jovem e continua mudando ativamente — se algo nesta ajuda divergir do comportamento real do aplicativo, confie no que você vê e, se possível, informe isso pelo repositório.
