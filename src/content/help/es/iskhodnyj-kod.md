# Código fuente

Ugolok es un proyecto de código abierto. Cualquiera puede estudiar exactamente cómo funciona todo por dentro, y confirmar que el cifrado y el modelo de privacidad prometidos están implementados tal y como se describen, no solo declarados de palabra.

Repositorio del proyecto: **git.ugolok.tech**

Con el tiempo, allí también aparecerán:

- compilaciones listas (versiones publicadas) de la aplicación;
- una lista de problemas y peticiones conocidos (issues) — se podrá informar de un problema encontrado o proponer una mejora;
- notas técnicas más detalladas para quienes quieran profundizar en los detalles de implementación o ayudar al desarrollo del proyecto.

El proyecto es joven y sigue cambiando activamente — si algo en esta ayuda no coincide con el comportamiento real de la aplicación, confía en lo que ves y, si puedes, infórmalo a través del repositorio.
