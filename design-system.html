Компоненты — кнопки и поля

Техническая страница, не часть приложения. Источник — src/styles/custom.css.

Обычные кнопки

minimal.css даёт заливку акцентом по умолчанию (primary CTA) — .btn--ghost её снимает (вторичное действие).

<button>
.btn--ghost
.btn--ghost.btn--danger
.btn--ghost.btn--warn
.btn--ghost.btn--good
.btn--ghost.btn--info

Круглая кнопка — только иконка

.icon-btn — готовый reset+вид для icon-only кнопок общего UI (2.25rem, background:none). Не подходит для кнопок на произвольном фоне/кадре (там своя подложка нужна) — см. .media-* классы в custom.css.

.icon-btn
.icon-btn.icon-btn--danger
.icon-btn.icon-btn--good
.icon-btn[disabled]

Скруглённая "таблеткой" кнопка — иконка + текст

.btn--pill — форма-модификатор (border-radius), независим от цвета. НЕ комбинировать с .icon-btn (та фиксированной ширины, только под icon-only).

.btn--pill
.btn--ghost.btn--pill
.btn--pill (только текст)

Группа кнопок "встык" (без зазора)

.btn-group — сегментированный контрол. Работает с любыми кнопками внутри (icon-only/текст/смешанные).

.btn-group (3 текстовые)
.btn-group (2 icon-only)

Поля ввода

.input--pill — форма-модификатор (border-radius). .input-icon — обёртка для декоративной иконки слева (особенно уместно для type="search").

<input>
.input--pill
.input-icon > input[type=search]
.input-icon > input.input--pill (составное)
