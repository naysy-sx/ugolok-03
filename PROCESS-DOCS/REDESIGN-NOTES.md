# REDESIGN-NOTES.md

Находки по ходу этапов редизайна, которые НЕ трогаются в рамках своего
этапа (правило REDESIGN-SPEC.md: "не рефакторить попутно") — записываются
здесь, чтобы не потеряться и не задавать один и тот же вопрос повторно.

## Этап 2 — мёртвый CSS: `.post__ava`/`.post__ava-fallback`/`.post__author`

`src/styles/custom.css` (~4509-4531) — шапка автора поста (аватар+имя),
заведена этапом 69. Новая карточка `.rec` (`post-card.jsx`) автора не
показывает — REDESIGN-SPEC.md/макет его не описывают, посты в канале
всегда от одного автора (`creatorPubkey`), показывать его на каждой
карточке избыточно. `.post__ava-fallback` делит правило с
`.cmt__ava-fallback` (комментарии) — их разделять нельзя не трогая
комментарии, поэтому удалять `.post__ava-fallback` в одиночку не стоит.

Что можно убрать при отдельном проходе по CSS (не в рамках редизайна):
`.post__ava`, `.post__author` — полностью мёртвые, использовались только
в старой шапке `post-card.jsx`, нигде больше не встречаются.

## Этап 4 — `DueChip` (post-card.jsx, этап 2) метит "сегодня" как "просрочено"

Живая проверка: запись со сроком, поставленным на СЕГОДНЯ (форма ввода
даты — `new Date(y, m, d)`, то есть 00:00:00 этого дня), с 00:01 того же
дня и до полуночи показывает чип "просрочено на 1 день" — `DueChip`
(`post-card.jsx:31-39`) сравнивает `dueAt` с `Date.now()` посекундно, не
календарным днём. Экран "Сегодня" (этап 4, `due-schedule.js`) группирует
ПРАВИЛЬНО — та же запись лежит в корзине "Сегодня", не "Просрочено" —
расхождение только в тексте чипа на самой карточке.

`DueChip` — контракт этапа 2, вне рамок этапа 4 (правило "не
рефакторить попутно"). Если трогать — вероятное решение: чип "просрочено"
только если `dueAt` строго меньше начала СЕГОДНЯШНЕГО дня (не текущего
момента), тем же способом, что `due-schedule.js` считает `startOfToday`.
